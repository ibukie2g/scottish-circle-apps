# schedule データ設計(案)

作成:2026-11-27(Claude、同日 伊吹確認)。アプリ・運営画面・Claude(スプレッドシート連携)が同じシートを読み書きするための約束。
画面から呼ぶ関数は `docs/API.md`。
なぜ作るか・決めたことは OneDrive の `Univ\スコサー\出欠アプリ\構想メモ.md`。デザインは同じフォルダの `03_デザイン.md`。

## 0. ファイルの分け方と個人情報の扱い

| ファイル | 中身 | 作り方 |
|---|---|---|
| **管理ファイル**(1つだけ) | グループの一覧、各イベントの控え(一覧を軽く出すため) | 最初に1回、エディタで `setup()` を実行して作る |
| **グループのファイル**(グループごとに1つ) | メンバー・イベント・候補日・回答・出欠・来てほしい人。**どのグループも同じ形** | 運営画面で「グループを作る」を押すと、アプリが自動で作る |
| **サークルの名簿ファイル**(既存。運動会の名簿) | 名前・ふりがな・男女・学年など | 既存。アプリは読むだけ(+下の「出欠アプリ登録」シートに書く) |

- すべてのファイルは、Googleドライブの「出欠アプリ」フォルダに置く
- **個人情報の約束**
  - サークルのグループ:グループのファイルには**名簿の参加者IDだけ**を書く。名前・学年・男女は名簿ファイルから読み、メモリ上で結びつける。名簿にいない人(新しく入った人・4年生など)がアプリで加わったときは、名簿ファイルの新しいシート「出欠アプリ登録」に名前などを書き、参加者ID(S01〜)をつける
  - サークル以外のグループ:本人が入れた**表示名**を、そのグループのファイルの「メンバー」シートに置く。ほかのグループのファイルには混ざらない
  - 使わなくなったグループは、ファイルごと消せる
- スクリプト プロパティ(コードに書かない):`ADMIN_PASSWORD`、`INDEX_SPREADSHEET_ID`(管理ファイル)、`FOLDER_ID`(出欠アプリのフォルダ)、`ROSTER_SPREADSHEET_ID`(サークルの名簿)
- シート名・列名は日本語。1行目が見出し。**列の順番を変えない**(Claudeが直接読み書きするため。Bに作り直すときもこの形をそのままテーブルにする)
- IDはアプリがつける。人が手で書き換えない

## 名簿ファイルに足すシート(サークルだけ)

### 9. 出欠アプリ登録
名簿(運動会の参加登録)にいない人が、サークルのリンクから自分で加わったときに書く。
| 列 | 例 | 説明 |
|---|---|---|
| 参加者ID | S01 | アプリがつける(運動会の P01〜 とかぶらないように S) |
| フルネーム | | 本人が入れる |
| ふりがな | | 本人が入れる |
| 学年 | 1年 / 2年 / 3年 / 4年 / その他 | 本人が選ぶ |
| 男女 | 男性 / 女性 / 答えない | 本人が選ぶ(絞り込みに使う) |
| 登録日 | | |

- 名簿の読み方:「フォームの回答 1」の 参加者ID(N列)・フルネーム・ふりがな・性別・学年 と、このシートを合わせて「サークルのメンバー一覧」にする
- AI(Claude)はこのシートの名前・ふりがなの列を読まない(運動会と同じルール)

## キャッシュ
- 管理ファイルのグループ一覧と、グループのファイルの読み取りは **10秒** キャッシュする
- サークルの名簿(名前の一覧)は **10分** キャッシュする(名前はめったに変わらないため。登録があったら消す)
- 書き込みは LockService でロックをとってから行い、終わったらそのグループのキャッシュを消す
