## 1. 点数を隠すタイミング(済)
- バレーの**決勝・3位決定戦が始まったら**、参加者の画面に運動の点数と順位を出さない。結果公開で出す
- 画面で隠すだけでなく、**サーバーが参加者向けの通信で点数を返さない**こと
- 隠し始める合図:**バレーの準決勝2試合(V-SF1・V-SF2)がどちらも確定したら**自動で隠す(運営のボタンは作らない)

## 2. 勝敗予想(済)
- 予想は**締め切るまで何度でも変更できる**。締め切るまで、予想の中身はだれにも見えない(サーバーが返さない)
- 全員がそろっても自動では公開しない。**運営が締め切りボタンを押す**(試合が始まって数分後の想定)
- 運営画面の予想ボタンの横に、受付を始めてからの**経過時間**を出す
- 締め切る前に試合の点数を確定したら、**自動で締め切る**
- 締め切ったら、予想した2チームに**人数だけの集計**を出す(例:Aチーム C勝ち4人/D勝ち2人)。名前は出さない
- 試合が確定したら、**全体の的中率**(2チーム合計)と**チームごとの的中率**を出す。「勝ち」の表示はしない
- 点数は今のまま:1試合ごとに「チームの中で当たった割合 × 2点」
- 素早く変更したときに古い予想が残らないこと(最後に押したものが必ず残る)

## 3. 名前クイズの判定と点数(済)
| 答え | 判定 |
|---|---|
| フルネームと完全一致(漢字・ひらがな・混ぜ書き) | 自動で1人分 |
| 名前だけ・名字だけと完全一致 | 自動で0.5人分 |
| 自己紹介に登録したあだ名と一致 | 自動で0.5人分 |
| それ以外で、だれかに近いもの(名前・名字の頭2文字以上、1文字違い、変換ミス、未登録のあだ名など) | **運営が判断**(1人分/0.5人分/×) |
| だれにも近くないもの | 自動で× |

- 判定の前に、最後の敬称を外す(さん・先輩・せんぱい・くん・君・ちゃん など)。まずそのまま比べ、だめなら外して比べる。あだ名の側も同じように外して比べる
- 同じ人を何回書いても、いちばん高い1回だけ数える
- 1つの答えが何人かに当てはまるときは、どちらか1人分
- 運営の判断画面:答えと候補の人(アプリが推測)を出し、[1人分][0.5人分][×]で決める。候補が出せないものは、チームメイトの一覧から選ぶ。同じ答えはまとめて1回で判断。**運営が結果を確定(公開)する時点で**判断していないものは×。判断するのは伊吹さん(クイズ終了後の「集計中」の1〜2分で行う)
- 「惜しい」の判断は、結果を公開した**あとでも直せる**ようにする(不服の申し立てがあったら、その場で点数を変える)。直したら総合点も計算し直す。判断はあまり厳密にしなくてよい(2026-11-14)
- **クイズのあとの自分の結果は、アンケートを送信したら見られる**(2026-11-14 決定)
  - 流れ:クイズ終了 → アンケート → 送信すると、自分の結果(何人書けたか、書けなかった人の名前「〇〇さん(ひらがな)を覚えよう!」、出身地クイズの正解)が出る
  - 「惜しい」答えで、まだ運営が判断していないものは「確認中」と出す。チームの点数や順位はここでは出さない(結果公開まで隠す)
  - 結果公開のあとは、今までどおりチームの内訳も見られる
- **ボーナス**(その人の正答率に足す):
  - 全員コンプリート(全員を何かの形で書けた。運営が0.5人分にしたものも含む):+10%
  - 全員フルネーム:+20%
  - **ボーナスで100%を超えてもよい**(7点の満点を超えてよい。チーム全員が全員フルネームなら 7 × 1.2 = 8.4点。仲良しポイントの合計は最大21.4点になる)。2026-11-14 決定
- クイズ画面の説明は簡単に:「フルネームで書くと高得点。漢字でもひらがなでもOK。名前だけ・名字だけ・あだ名でもOK(〜さん・〜先輩は付けてもOK)」。ボーナスの数字は出さない
  - ひらがなだけにはしない(「なんて漢字で書くの?」という会話のきっかけを残すため。2026-11-14)
- 「名前だけ・名字だけ」の判定は、名簿の名前が**空白で名字と名前に分かれているとき**だけ使える(`core_name.js` の `splitName_`)。分かれていない人は、名前だけの答えが「惜しい」側に回る。名簿を読み込むときに、空白で分かれていない人の**人数だけ**を運営画面に出す(名前は出さない)と、伊吹さんが名簿を直せる

## 4. 自己紹介のあだ名(済)
- 「、」「,」「/」で区切って最大3つまで登録できる(スペースは区切りにしない)
- 入力欄の説明:「呼ばれたい呼び方だけを書いてください。いくつかあるときは『、』で区切る。名前と関係ないあだ名がある人はここに書いてね(クイズで正解になります)」。見本は1人分の例(例:はな、はなちゃん)

## 5. 出身地クイズ(済)
- **3問**。出題の順番は人ごとにランダム
- 形は2種類:
  - B「〇〇さんの出身は?」→ 4つの県から選ぶ。出題する人は**福島以外を優先**。同じ人は2回出さない
  - C「〇〇県出身はだれ?(2人)」→ チームメイトの名前4人から選ぶ。同じ県が複数いるときは人数を見せ、**その人数まで選べる**。ぴったり当てたら正解。正解は3人まで(同じ県が4人以上なら、その県は出さない)。出せる県がなければBにする
- 1問1点(満点3点は今と同じ)
- 制限時間は**60秒**(1問20秒×3問の目安。名前クイズの120秒のあと)
  - 今は 15秒。コードの既定値(`DEFAULT_SETTINGS.quizOriginSeconds`、`setup.js` の初期値)を60にするだけでなく、**アプリ用スプレッドシートの「設定」シートに入っている15も60に直す**必要がある(シートの値が優先されるため)。直し方を報告に書く
- 選ぶと次の問題へ進み、最後に3問の答えを一覧で確かめて**「送信」ボタン**で送る(押した瞬間に送信はやめる)

## 10. Codex のレビューから取り入れること(2026-11-14 伊吹さん了承)(済。P1〜P3 すべて)
1〜9 を実装したあとに、P1 → P2 → P3 の順で行う。時間が足りなければ P3 から削る。1〜9 と重なるところは、1〜9 の実装のときに一緒に満たす。

### 1〜9 を実装するときに一緒に確かめること
- 点数を隠す:待ち画面だけでなく、参加者向けの通信のどの項目にも点数・順位が入っていないこと
- 予想:素早く変えたときと、返事が遅いときが重なっても、最後に選んだものが残ること
- 名前クイズ:未判定の件数がわかること。公開後に判断を直したら、総合点と本人の結果の両方が直ること
- 出身地クイズ:複数選択、戻って直す、時間切れのときの扱い
- 負荷テスト:中央値・p95・失敗件数に加えて、クイズ開始から問題が表示されるまでの待ち時間も測る

### P1(本番前に必ず)
- **P1-1 名前クイズの入力欄**(済):今は「番号・入力欄・ヒント」が横3列で、狭いスマホだと入力欄が細い。ヒントが同じ行にあるので、そのヒントの人を書く欄に見える(実際は対応していない)。→ 入力欄をほぼ横幅いっぱいにし、ヒントは別の枠にまとめる。キーボードが出ていても残り時間が見えるようにする(`participant_css.html` 298行あたり、`participant_js.html` 725行あたり)
- **P1-2 運営画面の通信待ち**(済):運営の通信に時間切れがなく、返事が来ないと「保存中」のままになる。→ 一定時間で「結果を確かめてください」と出し、最新の状態を取り直せるようにする。「保存されていない」と決めつけない。**クイズ開始はやり直すと開始時刻が変わる**ので、単純にもう一度送らせず、まず状態を確かめる(`admin_script.html` 165行あたり)
- **P1-3 準決勝の修正・取消の警告**(済):組み合わせが変わると、決勝・3位決定戦・ドッジの得点や確定、関連する予想が消える。→ 影響がある修正・取消だけ、消えるものを具体的に出して確認する。サーバー側の動きは変えない。保存後は関連する試合も取り直す(`admin_script.html` 718行あたり、`api_admin.js` 163行あたり)
- **P1-4 結果公開の前の確認**(済):公開の確認画面に「試合の確定数/18、お題の入力数/12、クイズの回答数、未判定の件数」を出す。未判定は公開のときに×になることも書く。人数が足りなくても公開は止めない

### P2
- **P2-1 アンケート済みを参加者ごとに**(済):今は端末ごとのフラグ(`participant_js.html` 129行 `surveyDone`)なので、端末を貸すと次の人も回答済みになる。→ 参加者ごとに持ち、サーバーの送信済みの状態と合わせる(「アンケートを送ったら自分の結果」と一緒に直す)
- **P2-2 点数欄の Enter で確定しない**(済):今は2つ目の点数欄で Enter を押すと確定する(`admin_script.html` 667行あたり)。→ Enter は入力を終えるだけにし、確定は大きなボタンで
- **P2-3 答え合わせを早く見せない**(済):今は出身地クイズに早く進めるので、早く終わった人がアンケートまで済ませると、ほかの人が名前を書いている間に答えを見られる。→ アンケートを送っていても、**名前クイズの全員の締め切り(nameEndsAt)までは**名前の答え合わせを出さない。「名前クイズが終わったら表示します」と出す
- **P2-4 色とボタン**(済):運営画面の黄色チームの白文字は濃い文字にする。赤・緑の小さい白文字も確かめる。よく使う小さいボタンは高さ48pxくらいにする。チームの色とA〜Dの文字を並べて出すのは今のまま
